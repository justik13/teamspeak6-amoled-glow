# AMOLED Cyber Glow для TeamSpeak 6

<p align="center">
  <img src="Thumbnail.png" alt="AMOLED Cyber Glow" width="128" />
</p>

Тёмная тема для TeamSpeak 6 с глубоким чёрным фоном (#000000) для OLED-экранов, неоновой индикацией голоса и удобным разделением каналов.

## Основные особенности

- Фон #000000 отключает пиксели на OLED и не слепит глаза в темноте.
- Голосовые каналы оформлены отдельными карточками с отступами, поэтому список не сливается в сплошной текст.
- Индикация микрофона: зелёное кольцо вокруг аватара во время речи, красное при выключенном микрофоне и жёлтое в статусе «Отошёл».
- В чате подсвечиваются собственные сообщения, ссылки подчеркиваются, а блоки кода оформлены в стиле терминала.
- 12 цветовых вариантов под разные предпочтения, включая режим для обычных IPS-мониторов.

## Доступные варианты темы

- AMOLED Pink (неоновый розовый)
- AMOLED Cyan (бирюзовый)
- AMOLED Purple (фиолетовый)
- AMOLED Amber (янтарно-оранжевый)
- AMOLED Emerald (изумрудный)
- AMOLED Ruby (рубиновый)
- AMOLED Dark (минималистичный тёмный с фиолетовым акцентом)
- AMOLED Silver (серебристый)
- AMOLED Abyss (тёмная морская волна)
- Midnight Slate (тёмно-серый фон для IPS/LCD мониторов, скрывает засветы матрицы)
- Cyber Graphite (графитовый)
- Catppuccin Mocha (кофейно-пастельный)

## Установка

### Автоматическая установка

1. Нажмите правой кнопкой мыши по меню «Пуск» и откройте PowerShell (или Терминал).
2. Вставьте команду и нажмите Enter:

```powershell
irm https://raw.githubusercontent.com/justik13/teamspeak6-amoled-glow/main/update.ps1 | iex
```

Скрипт автоматически скачает тему и распакует её в каталог расширений TeamSpeak.

### Установка вручную

1. Нажмите зелёную кнопку Code вверху страницы репозитория и выберите Download ZIP.
2. Распакуйте архив и переименуйте полученную папку в `amoled.dark.minimalistic`.
3. Переместите папку в каталог расширений:
   ```text
   %APPDATA%\TeamSpeak\Default\extensions\amoled.dark.minimalistic
   ```
   Чтобы быстро открыть эту папку, нажмите Win + R, вставьте `%APPDATA%\TeamSpeak\Default\extensions` и нажмите Enter.

## Включение темы в TeamSpeak

1. Откройте TeamSpeak 6.
2. В левом нижнем углу нажмите значок шестерёнки (Настройки) и перейдите в раздел «Внешний вид».
3. В блоке «Стандартная тема» выберите Dark.
4. Ниже включите переключатель «Использовать внешнюю тему» и выберите нужный цвет из списка.
5. Полностью перезапустите TeamSpeak: нажмите правой кнопкой мыши по значку TeamSpeak в трее возле часов Windows и выберите «Выход», затем запустите программу снова. Без полного перезапуска клиент не обновит оформление.

## Обновление темы

Для обновления темы до последней версии запустите команду автоматической установки в PowerShell ещё раз.
